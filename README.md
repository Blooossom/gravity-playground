# 맘대로 — 중력 놀이터

브라우저에서 공을 던지고 중력, 탄성, 블랙홀을 바꾸며 노는 Canvas 물리 장난감입니다.

## 실행

Node.js 22 이상 권장. 앱 자체는 별도 설치나 빌드가 필요 없습니다.

```sh
python3 -m http.server 4173 --directory dist
```

http://localhost:4173 에서 엽니다. ES 모듈을 사용하므로 index.html을 파일로 직접 열지 않고 HTTP 서버로 실행합니다.

## 조작

- 공 던지기: 클릭으로 추가, 드래그한 방향과 거리에 따라 발사
- 잡아 끌기: 공을 잡아 이동하고 놓아 던지기
- 블랙홀: 클릭으로 설치, 기존 블랙홀 클릭으로 제거 (최대 6개)
- 방향 화살표 / 세기 / 탄성 / 크기 / 흡인력 조절
- 지구, 달(0.2g 근사), 무중력, 뒤죽박죽(3초마다 방향 회전) 프리셋
- 공 30개 추가, 공 비, 궤적, 일시정지, 초기화
- B: 던지기 도구와 공 한 개 추가 / G: 잡기 / H: 블랙홀 / Space: 일시정지
- 공 최대 350개. 터치와 마우스 모두 지원합니다.

## 검증

```sh
node --test tests/physics.test.mjs
```

중력, 충돌 운동량, 벽 반사, 블랙홀 흡수, 최대 개수의 유한 좌표·경계를 검사합니다.
물리는 재미를 위한 근사 시뮬레이션이며 공기 저항과 속도 제한이 있습니다.
이 제작 세션에서는 브라우저 도구 연결 장애로 시각 및 터치 검증을 완료하지 못했습니다.

## 구조

- `dist/index.html`: 한국어 인터페이스
- `dist/style.css`: 반응형 스타일
- `dist/app.js`: 렌더링과 조작
- `dist/physics.mjs`: 고정 시간 간격 및 공간 격자 기반 충돌 시뮬레이션
- `.openai/hosting.json`: Sites 호스팅 설정

외부 의존성 없이 작동합니다. 웹 폰트는 Google Fonts에서 읽으며 연결이 없으면 시스템 글꼴을 사용합니다.
